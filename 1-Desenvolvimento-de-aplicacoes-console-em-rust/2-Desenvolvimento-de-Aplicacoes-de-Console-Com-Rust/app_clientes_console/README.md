# 🦀 App Clientes Console

Aplicação interativa de console desenvolvida em **Rust** para gerenciamento de clientes em memória (CRUD).

## 🚀 Funcionalidades

- **1 - Cadastrar cliente**: Cadastro interativo informando ID, Nome, CPF e Endereço.
- **2 - Alterar cliente**: Exibe os dados atuais e permite atualizar campos desejados.
- **3 - Excluir cliente**: Busca o registro por ID e remove da memória com confirmação (`S/N`).
- **4 - Listar clientes**: Exibe tabela alinhada com todos os clientes registrados.
- **0 - Sair do programa**: Encerra a aplicação.

## ⚙️ Como Rodar

```bash
cargo run
```

## 🛠️ Tecnologias
- **Rust (2024 edition)**
- **clearscreen crate v2.0.1** (para controle e limpeza do terminal)
